## Key Patterns
- **Hash Map** — O(n) lookup (Two Sum)
- **Two Pointer** — opposite ends on sorted input
- **In-place modification** — swap/overwrite without extra space
- **Prefix Sum** — range queries in O(1) after O(n) build

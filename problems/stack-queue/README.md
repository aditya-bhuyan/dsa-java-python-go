## Key Patterns
- **Matching brackets** — push open, pop and match on close
- **Auxiliary stack** — track min/max alongside the main stack
- **Monotonic stack** — maintain a decreasing stack; pop when a larger value arrives
- **Index stack** — store indices instead of values to compute distances

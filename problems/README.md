## Problem Folder Layout

Every problem follows this structure:

```text
<topic>/<problem-name>/
├── README.md        ← problem statement, constraints, complexity analysis
├── Benchmark.md     ← performance benchmarks across languages
├── java/
│   ├── Solution.java
│   └── SolutionTest.java
├── python/
│   ├── solution.py
│   └── test_solution.py
└── go/
    ├── solution.go
    └── solution_test.go
```

## 📖 About

This repository documents my journey of mastering **Data Structures and Algorithms** over a **10-month learning plan**.

The objective is not only to solve coding problems but also to:

- Learn DSA concepts thoroughly.
- Compare implementations in **Java**, **Python**, and **Go**.
- Understand language-specific idioms.
- Improve problem-solving skills.
- Build a reusable reference for interviews.
- Prepare for Software Engineering, Cloud Native, and AI coding opportunities.

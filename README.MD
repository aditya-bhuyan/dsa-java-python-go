## 📅 12-Week Learning Plan

| Month | Week | Topic | Problems |
|-------|------|-------|----------|
| **Month 1** · Core DS | Week 1 | [Arrays](problems/arrays/) | Two Sum, Best Time to Buy Stock, Remove Duplicates, Move Zeroes, Rotate Array |
| | Week 2 | [Strings](problems/strings/) | Valid Anagram, Longest Common Prefix, Reverse String, Palindrome, Group Anagrams |
| | Week 3 | [HashMap & HashSet](problems/hashmap-set/) | Contains Duplicate, Happy Number, Isomorphic Strings, First Unique Character |
| | Week 4 | [Linked List](problems/linked-list/) | Reverse List, Middle Node, Cycle Detection, Merge Lists |
| **Month 2** · Trees & Graphs | Week 5 | [Stack & Queue](problems/stack-queue/) | Valid Parentheses, Min Stack, Daily Temperatures, Next Greater Element |
| | Week 6 | [Trees](problems/trees/) | Max Depth, Inorder Traversal, Same Tree, Symmetric Tree, Diameter |

| | Week 8 | [Graphs](problems/graphs/) | Number of Islands, Clone Graph, Course Schedule, Flood Fill |
| **Month 3** · Patterns | Week 9 | [Sliding Window](problems/sliding-window/) | Max Average, Longest Substring, Min Window, Permutation in String |
| | Week 10 | [Dynamic Programming](problems/dp/) | Climbing Stairs, House Robber, Coin Change, LIS |
| | Week 11 | [Greedy](problems/greedy/) | Jump Game, Gas Station, Assign Cookies |
| | Week 12 | [Mixed Interview Practice](interview-notes/notes.md) | 2–3 random mediums per day |

## 🎯 Interview Notes

[`interview-notes/notes.md`](interview-notes/notes.md) contains:
- **5 problems per topic** with LeetCode links (Trees, Graphs, DP, Sliding Window, Binary Search, Arrays, Strings)
- **6 interview questions per topic** — conceptual, complexity, trade-offs, follow-ups
- **Weekly random practice schedule** — 5 weeks of pre-selected mixed problems
- **Data Structure Translation Challenge** — implement ArrayList, LinkedList, HashMap, HashSet, TreeMap, PriorityQueue, Stack, Queue, Comparator, Comparable, and Streams in Java → Python → Go from scratch
